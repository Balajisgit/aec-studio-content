# Session 9 · Two PCs and associates: setup guide and Git workflow

Wrote a step-by-step guide for installing AEC Agent Studio 2 on a second PC and for associates sending changes through GitHub pull requests.

## Done

- Setup-AEC-Studio-on-another-PC.md: install Node and GitHub Desktop, clone Balajisgit/aec-agent-studio, core.fileMode false, copy .env, choose data (copy data\ and files\ or start from data-bundle\), first start, checks, daily use, troubleshooting.
- Same guide covers associates: invite as collaborator, protect main with required pull requests (bypass allowed for the owner), they work on a branch and open a pull request, the owner reviews and merges on github.com.
- Clarified: the code syncs between PCs through GitHub; each PC keeps its own database (requests, projects, approvals, chats, session memory, files).
- Clarified: the folder name and place can differ per PC; keep the install outside OneDrive-synced folders.

## Decisions

- Owner works on two PCs (office and home) with one Claude subscription; code shared via GitHub.
- Until data sync exists, one PC is the home for Studio work; data moves only by copying data\ and files\ with both apps closed, never via a cloud-synced studio.db.
- Associates change code only via branch and pull request; the owner merges; associates don't use the local Release button.
