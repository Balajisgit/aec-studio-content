## Decisions

- The engine holds the design intent (graph, parameters, validation, light geometry, log); hosts realise it. The Studio is only the interface and passes on what pipelines instruct.
- Element types: node, segment (wall and opening are segment types), space, object, level.
- Outside canvases connect by route 1 (in the page, no AI tokens) or route 2 (API or MCP bridge). One way first; the host gets copies of results, not operations.
- Every canvas, the built-in one included, takes route 1, so any canvas can be the default.
- Claude gets credit for pipeline and freestyle work; the owner only for manual edits.
- A project can use several pipelines, or none; chats are listed in the project's History with tags.
