# R147 · A beam hosted on a wall: an Object that goes on a host without being an opening

Owner: "A beam hosted on the wall: that small kernel change. ... go with this." The kernel lets a Library Object say it goes on a host (on: "host") without being an opening; with no at or width it runs the host wall's whole length and cuts no gap. Moving or removing the wall takes the beam with it. Its height comes from the R144 relationship (beam_on), written in by the Studio; the kernel only reads the beam's own parameters. Content: a beam Object in the Library. Build after the R142 to R146 block merges.
