# R140 · Programme in and out: model.json carries the programme options; import a programme from CSV, Excel or JSON as a new option

Owner: 'import program also'; export carries the programme: 'yes'; formats: 'both' (CSV and Excel). Export writes the programme options (each option, its name, the current one) beside the model, as the notes are (R134), never in it; a model.json imported as a new project brings them. In Edit programme, Import takes a table (use, how many, m² each, for how many, floor) from CSV, Excel or our JSON, as a new option by default or replacing the option shown when chosen; nothing overwritten without asking; a use the typology does not know is matched where clear, else asked. Programme from a brief gets the same 'as a new option' choice. The kernel is unchanged.
