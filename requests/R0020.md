# R20 · Move Studio to a private server on the owner's Claude subscription

Run AEC Studio on a small cloud server for the owner only (option A). Claude Code there signs in once with a one-year token from claude setup-token (CLAUDE_CODE_OAUTH_TOKEN; the app doesn't use --bare). The app runs as a service (systemd): starts at boot, restarts itself after a server update or a backup restore, so no Start-Studio.bat; at most a Restart button on the Studio page. Locked down: reachable only through a private network (Tailscale) or a sign-in (Cloudflare Access), since today the app has no login. Its own Git access (a deploy key or token for the content repository) for records. One database for both PCs and the phone, so projects no longer move by export and import; files and backups as prepared in phase 6 (assets by fingerprint, R2 later). Renew the token yearly. For the owner's own use only: other people (Bikal, clients) must not run on the owner's subscription (Anthropic's terms); sharing it would mean per-person Claude sign-in or per-client API keys, a separate build.
