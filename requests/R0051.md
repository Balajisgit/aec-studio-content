# R51 · Corrections reader: learn from the owner's corrections of agent steps

When the owner undoes or changes an agent's step (Innowa or a pipeline) soon after, the log holds it but nothing reads it. A reader pairs agent steps with the owner's corrections and proposes, for the owner to accept: a lesson for that agent, a sense check, or a rule note when it keeps happening.
