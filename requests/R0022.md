# R22 · Studio for clients: accounts, each on their own Claude key

After R20. Clients pay the owner a Studio subscription; their Claude use is on their own Anthropic API key, billed to them by Anthropic (never on the owner's Claude subscription, never resold or marked up). Build: client accounts with sign-in, each client's projects, runs and requests kept apart; each client enters their own API key in their settings, stored safely and used only for their chats and runs; usage shown per client (from the run costs); the owner's shared Library and pipelines available to all, a client's Project Objects stay theirs unless the owner brings them in. Hosted Studio does not collect clients' claude.ai sign-ins or subscription tokens. Before selling: confirm with Anthropic sales and a lawyer (Commercial Terms apply to running Claude Code in a product).
