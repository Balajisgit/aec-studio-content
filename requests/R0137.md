# R137 · A playbook run on a design option gets no programme: the test fit says there is none

Found while making the Northwind Labs mockup: the test fit run on a design option stopped with 'There is no programme to fit'. A run reads the programme by its own project's id (managers/pipelines/runs.js), and a design option keeps none of its own: it reads its project's, in the programme option it answers. Fix in the app: a run on a design option gets the programme of the option that design answers (and writes there, programme_put). The test fit script in the content stays as it is. Owner: 'ok'.
