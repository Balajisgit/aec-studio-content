# R150 · Model defaults in three parts (Typology, Construction, Standards), a generic placing engine, and an RCC frame Construction from walls to finished structure, with Structure it for columns

Owner: "Can we create a templete(a model default) that start from placing the wall upto finishing the structure", "Need to organize model defaults into more logical and structured way", then "Ok write the request". Agreed in discussion: the template says what, the Studio knows how; a layout drawn as lines only (by hand or by Innowa) plus a template gives the whole shell with no tokens.

1. Model defaults in three parts, each versioned in the content and picked by a template (layers as now: BuilderPluss, firm, template, project overrides):
- Typology (what it is for): room uses with smallest sizes, window, wet; rooms kept apart; ratios; measures; the typology checks' values.
- Construction (how it is built): the Objects used (outer wall, partition, slab, beam, column, lintel, parapet, railing), placing rules, relationships, default openings, floor height, structure checks.
- Standards (the firm's way): level names and codes, room numbering, standard sizes (column, beam, lintel).
A template = one of each (Villa = Villa + RCC frame with brick + standards). Templates rewritten as new versions (Villa 2.0.0…); projects on 1.0.0 keep working.

2. A generic placing engine in the Studio, like the checks and relationships engines: rules as data (on: line, point, opening, room edge, floor, void; when: a formula; place: an Object; params: formulas), applied after every step in the same step, anything set by hand kept and listed when it differs. Replaces the coded walls, floors, slabs and beams (R148). New rules then need no code; a new kind of place (beyond the six) is a rare code change.

3. Construction rules for an RCC frame house, walls to finished structure: a wall on every room line (outer bounding one room, partition between two; lines marked open, zone or reference stay bare); floors; slab per floor and a roof slab over the top floor; beams; lintels over openings; optional sunshades; parapet round the terrace; railing round the stair opening; checks for long spans and walls with nothing under them. Plinth beam and footings later (need a foundation level).

4. Structure it: a script in the content (no tokens) proposing two or three column layouts with their beam spans; the owner picks one; its columns are then held as set by hand; footings follow the columns.

Open questions for the owner: frame, load-bearing, or both as two Constructions; names of the three parts; relationships inside Construction or one shared file; default sizes (column 230x300, beam 230x450, lintel 150, parapet 1000) or the firm's own; windows by rule or by hand.
