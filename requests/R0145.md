# R145 · Canvas: another level shown faint under the one being drawn (the floor below by default, any can be chosen)

Owner: 'only thisng is - when starting a level has its lower floor(can be chosen) as undelay'. On the canvas, a level being drawn shows another level faint underneath: the floor below by default, any level chosen from a picker, or none. Its corners and lines can be snapped to but not selected or changed; it is a view only (nothing in the model changes, the kernel is untouched). A new level opens with it on, so a slab edge can be traced or run past the walls below for a cantilever. The rest (the slab first, the floor system: walls, beams, slab by parameters) is controlled through R142 to R144 once they are done (owner: 'we can control this thru the above requests once done').
