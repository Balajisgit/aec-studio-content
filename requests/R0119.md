# R119 · Cloud sessions can't start: the app runs Claude with --cloud and --print together, which is refused

Owner: "start a cloud session to make a script that lists every room's area". cloud_start failed, and no session was made. The error: "--cloud cannot be combined with --print. Starting a new cloud session with --cloud is interactive only: drop --print, or drop --cloud to run locally. To message an existing cloud session instead, pass its ID: claude -p "message" --cloud <session-id>". So starting a new session needs another way than --print (by the error, messaging an existing session that way is allowed; cloud_send not tried). Once fixed, start the room-areas script session: a read-only project report of each room's level, name, use, net and gross area, with totals.
