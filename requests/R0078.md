# R78 · Files a pipeline makes go to the project on approval: a folder per pipeline, versioned names, where each came from; heavy files can stay on the PC by path

Owner, 12 Nov 2026: files reach the project's Files 'on approval' (at the run's decision, e.g. the image review R75); 'Folder per pipeline' (Renders, Boards...; the brief's own files stay at the top); never overwrite: a version in the name; each file records its run, stage, PC and date. Heavy files (owner: 'can have a option to stored locally with its file path stored in the db'), e.g. Detail an Object's .blend/.usdc: kept on the PC that made them, the database holding the Helper's named folder (not a drive letter), the path inside it, sha256, size and date; checked by fingerprint when used, shown as missing if moved; a small preview (.glb, image) still kept in Storage so the browser can show it; a Library Object must have its files in Storage before it is proposed. Intermediates (masks, logs) stay with the run. Serves R57 (schedules as PDF) too.
