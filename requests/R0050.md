# R50 · Kernel split: design kernel and a swappable geometry engine

Owner: "So how we can separate our kernel from the occt overlap and make it for what actually it is." kernel/ becomes the design kernel (model, ids, ops, rules, log, topology, heights, objects, views, engine.js: the questions it may ask). geom/light/ is our geometry engine (basics, faces, outlines, cut, lift, parts): shapes only, no building words. Nothing outside kernel/ imports geom/; geom/ imports nothing from kernel/; a check enforces it. No change in behaviour; the 33 files using the kernel keep importing kernel/index.js. geom/occt/ is left for a later request (slopes, 3D cuts, true solids, with R46).
