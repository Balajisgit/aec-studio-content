# R65 · Put in a wall: a canvas tool that places a door, window or gate Object into an existing wall or fence line

The owner (11 Nov 2026), on placing a door into an existing wall: "Same for window?". One tool for both, and gates in fences: pick the Object (door, window, gate) from the Library on the floating tool bar, click a line built as a wall (or a fence): the line is split round the click at the Object's default length (centred, snapped to 10 mm), and the piece gets the Object's meaning (Door, Window, Gate) built as that Object, its host wall filling above and below. Afterwards: drag either end to change its width, or slide it along the wall (the wall pieces either side follow); removing it joins the wall back into one line.
