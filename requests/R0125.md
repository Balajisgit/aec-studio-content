# R125 · The Studio connector saves a file into a project's files

A connector tool (files_put) saves a file given in a claude.ai chat (a plan picture, a brief, a photo) into a project's files, with the same checks as an upload in the Studio: the person's rights on the project, the size limit, the file type.
