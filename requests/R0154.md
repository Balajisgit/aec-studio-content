# R154 · Three chat homes: project chats belong to their project (and design option), Library chats, App chats; lessons go where their subject lives

Owner: "project chat has to move to project", then on the open questions "1. explain 2. allowed after 3. explain 4. yes those related to the specific model" and "ok wite and build as per ur suggestion". Every chat has a home: a project (and the design option whose canvas it started on), the Library, or the App. A new chat takes its home from the page it starts on. The chat panel switches to the open project's chats; a pin keeps the chat you are in while you move between pages. A chat works on its own project; changing another project from it is allowed after Innowa asks and the owner says yes. The project page shows its chats grouped Project / Option A / Option B; copying an option does not copy its chats. Chats tied to a model go out and back in with its model.json. Library changes made from a project are recorded in that project chat and note and in the Library entry history. App requests made from a project chat get a line in that chat (and when done). Library chats and App chats are separate; sessions (memory_record) only in App chats. Lessons go by subject: design to the Library, the job to project notes, the app to App memory; a project lesson can be promoted to the Library. Existing chats are moved home: a chat that wrote a project note goes to that project.
