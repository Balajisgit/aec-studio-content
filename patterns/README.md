# Layout patterns (R53)

Rooms the owner accepted, kept so Innowa can start from them instead of drawing from scratch: `patterns/<id>.json`, each a set
of spaces on one level with the walls that bound them, their doors and windows, the Placements on or in them and the Objects
they use, at positions relative to the pattern's lowest corner.

- **Kept** by the owner: on the Canvas, select a space and choose *Keep as a pattern*; or ask Innowa to save one. The app
  commits it straight to main, like a lesson, because the owner decided it.
- **Used** by Innowa: it looks at the patterns before drawing rooms and, when one fits and the owner agrees, puts it into the
  project as one undoable step, joining corners and walls already there.
- **Removed** on the Library page.
